# 玄凤点点桌宠

Cockatiel Diandian Desktop Pet

Windows 玄凤鹦鹉桌面宠物项目，同时维护二维与 Unity 三维两条版本路线。

- **v1.6 二维版**：Python 桌宠、帧动画、叫声、互动和可视化编辑器，新增个人照片生成整套外观。
- **v2 三维版（制作中）**：Unity 工程，包含三维模型、骨骼、展翅和桌面窗口功能。**目前仅为初版，三维建模仍在制作中，模型细节和整体精细度尚待完善。**

详细使用、构建与版本记录见 [项目说明.md](项目说明.md)。

## v1.6：用自己的照片生成玄凤桌宠

1. 打开 v1.6.0 编辑器的“外观生成”，选择自己的玄凤照片。
2. 填写自己的图像服务 API Key。默认使用 OpenAI；也可填写兼容 Images Edit **JSON** 接口的 HTTPS 地址及模型名。
3. 点击“生成整套动作”。共生成四组、32 个默认姿态；失败可继续未完成组，也可单独重生成一组。
4. 逐组检查图片后点击“预览这套外观”，到“动作”页查看动画，最后“保存并应用”。可随时“恢复默认点点”后保存。

生成会把照片和姿态参考图发给所选服务，费用由使用者的 API 账号承担。密钥仅用于本次编辑会话，关闭编辑器即清空，不保存到项目。生成后的动作图保存在个人本地目录，并可随个人内容保留；原照片、原始默认素材不会被覆盖。自行追加的额外动作姿态仍可在动作页编辑。

这项功能用于 **v1 二维版**。v2 三维建模仍在制作中。已完成模拟服务和本地保存/恢复测试；真实照片的生成质量、动作一致性和各服务兼容性仍需使用实际账号验证，生成后请先预览。

## 开发入口

- 二维版：`app/`；本机可双击 `编辑点点.cmd` 打开编辑器。
- 三维版：用 Unity **6000.6.7f1** 打开 `unity/Diandian/`。
- 二维打包：在安装了项目依赖的 Python 环境中运行 `python build.py`。
- 第三方许可：`licenses/`。

## 从 GitHub 获取项目

先安装 Git 和 Git LFS，再运行：

```powershell
git lfs install
git clone https://github.com/Coredell16/diandian-desktop-pet.git
```

大型三维素材通过 Git LFS 保存；若克隆时未取回素材，在项目目录运行 `git lfs pull`。

## GitHub 同步范围

源码、必要图片/音频/模型、Unity 的 `Assets/`（含 `.meta`）、`Packages/` 与 `ProjectSettings/` 应纳入版本管理。

`.gitignore` 排除 Unity 缓存、日志、本机设置、Python 缓存，以及 `outputs/` 和构建临时目录。忽略规则不会删除本机文件；历史安装包和归档仍保留在本机，不会随源码自动备份。

需要分享安装包时，可另行上传到 GitHub Releases。修改源码后，需要提交并推送才会同步到 GitHub；朋友的客户端自动更新还需要单独配置发布地址，详见项目说明。
